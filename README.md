# BlackVolt SMP downloads

Download **blackvolt-smp-0.1.0.jar** from this branch. Requires Minecraft Java **1.21.11**, Fabric Loader **0.17.3 or compatible newer**, Fabric API for **1.21.11**, and Java 21.

Put the JAR in your Fabric instance's `mods` folder, then launch Minecraft. Press Right Shift in a world to open the GUI. In Modrinth App, open the instance folder and place the JAR in its `mods` directory.

This is a client-only mod. Do not install it on a dedicated server. Public-server anti-cheat compatibility is not certified. Windows, audible sounds, and authenticated multiplayer have not been fully tested.

SHA-256 is provided in `SHA256SUMS` so you can verify your download.
